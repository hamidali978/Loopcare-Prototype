# LoopCare — AI healthcare handoff auditor (prototype)

LoopCare reads a **synthetic** discharge/handoff document, uses Gemini to extract action items (owner, due date, status, dependencies, evidence, exact source excerpt), then applies **deterministic TypeScript rules** to flag open loops for a human to verify.

> **Not clinically validated. Not a medical device. Not HIPAA compliant.** Use fictional data only. Findings say what the *provided text* doesn't show; they never prove a care step was missed.

## Features
- Dashboard: metrics, exception queue, filters (severity, rule, document, search), extracted-items tables
- Rules: missing owner, missing due date, completed without evidence, unresolved dependency, pending result with no documented review
- Each finding: source excerpt (checked against the pasted text), explanation, "a human should verify" list
- Voice dictation (Web Speech API) into an editable box, plus read-aloud (SpeechSynthesis) per finding or for all high-priority ones
- JSON export, loading and error states
- **Demo mode** (labelled) when `GEMINI_API_KEY` is missing or Gemini fails
- No database, no auth, no persistence; documents are never logged

## Run locally
```bash
npm install
cp .env.example .env.local     # add your key (optional: without it, demo mode runs)
npm run dev                    # http://localhost:3000
npm test                       # vitest
npm run build && npm start     # production
```
Requires Node 18.18+ (Node 20 recommended).

## Gemini API key
1. Create a key at <https://aistudio.google.com/apikey>.
2. Put it in `.env.local` as `GEMINI_API_KEY=...`. It is only read in the server route (`src/app/api/audit/route.ts`); never use a `NEXT_PUBLIC_` prefix.
3. Optional: `GEMINI_MODEL` (default `gemini-2.5-flash`).

## Deploy to Vercel
1. Push the project to a Git repo and import it at <https://vercel.com/new> (framework: Next.js, no extra settings).
2. Add `GEMINI_API_KEY` under Project → Settings → Environment Variables, then redeploy.
3. Or via CLI: `npx vercel` then `npx vercel --prod`.

Free-tier quotas (Vercel and Gemini) and eligibility can change; check current limits. The API route sets `maxDuration = 30`; your plan may cap function duration lower.

## Troubleshooting
- **"Demo results" banner**: key missing, invalid, quota exceeded, network blocked, or the model output failed validation. Check the key and server logs (only an error class is logged, never document text).
- **Dictation missing/failing**: Web Speech API works best in Chrome/Edge/Safari over HTTPS or localhost; allow microphone access. Typing always works.
- **No read-aloud sound**: browser/OS voice support varies.
- **Excerpt warning on a finding**: the model's excerpt wasn't found word-for-word; check the original text.
- **Build errors after changing Node versions**: delete `node_modules` and `.next`, then `npm install`.

```
tests/                       rules, schema and demo-data tests
```
Note: the shadcn/ui-style components are hand-written (same cva + tailwind-merge pattern), not generated by the shadcn CLI.
